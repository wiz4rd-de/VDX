# Each line:  id | setup | "line 1" | "line 2" | cursor
#   setup   space-separated steps from the first-run state (PLAY, INT 1 INIT VOICE, CLEAN):
#           1..32           press that numbered button
#           INT CRT EDIT FUNC STORE PINT PCRT OPSEL NO YES   press that button
#           h:i=v           host automation of voice parameter i (no mode change, R-S2)
#           p:i=v           programmer change of voice parameter i (F-3)
#           f:n=v           host automation of function parameter n
#           g:id=v          programmer change of panel global id (vdx::Global)
#           d:x             data-entry slider at position x
#           w:ms            wait (render) ms milliseconds
#           crt             New cartridge (UNTITLED, 32 x INIT VOICE)
#           splash          start the power-on splash
#           reset           load a corrupt state blob, run the splash, wait 1.6 s
#           reject          a rejected file (FORMAT CONFLICT!)
#           badsum          a file-loaded voice with a checksum mismatch
#           rxvoice         a single-voice dump received over MIDI
#           note:n          MIDI note n on and off (channel 1)
#           -               nothing
#   cursor  - (none) or row,col of the blinking cursor
#
# Reference values: INIT VOICE (R-P10) is algorithm 1, OP1 output level 99, all
# rates 99, levels 99/99/99/0, break point 0, coarse 1, fine 0, detune 7, LFO
# speed 35, key sync on, wave triangle, P MOD SENS 3, transpose 24, pitch EG
# levels 50. Function defaults (§4.2): poly, bend range 2, step 0, wheel range
# 99 with pitch assigned. INT 2..9 = E.PIANO BELL BASS BRASS ORGAN MARIMBA
# STRINGS PAD (§15.3). Voice parameter index of OP1 byte k = 105 + k.
